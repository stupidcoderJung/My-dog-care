## 아키텍처 패턴

### 1. MVVM + Combine
- **Model**: Core Data 엔티티 + Swift 구조체
- **View**: SwiftUI 뷰 컴포넌트
- **ViewModel**: Combine 기반 상태 관리
- **Binding**: @Published 프로퍼티티를 통한 데이터 바인딩

### 2. 서비스 지향 아키텍처
- **분리**: 비즈니스 로직을 서비스 계층으로 분리
- **의존성 주입**: 뷰모델에 서비스 주입
- **프로토콜 기반**: 프로토콜을 통한 인터페이스 정의

### 3. 컴퓨터 비전 파이프라인
```
Camera Input → Vision Service → YOLO Detection → ReID Tracking
      ↓
State Analysis → Packet Builder → Event Uploader → Backend
```

## 데이터 흐름 아키텍처

### 1. 실시간 비전 파이프라인
```
카메라 프레임 → VisionService
    ↓
YOLO 객체 탐지 → ReID 개체 식별
    ↓
DeepSort 추적 → 상태 분석
    ↓
StatePacketBuilder → EventUploader
    ↓
HTTP POST → 백엔드 API
```

### 2. AI 채팅 파이프라인
```
사용자 입력 → ChatView
    ↓
ChatService → HTTP POST
    ↓
백엔드 Chat API → LLM 처리
    ↓
응답 수신 → ChatView 표시
```

### 3. 데이터 저장 파이프라인
```
사용자 입력 → View → ViewModel
    ↓
Core Data 저장 → PersistenceController
    ↓
로컬 데이터베이스 저장
```
