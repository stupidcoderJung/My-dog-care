# 프로젝트 개요

## MyDogCare - AI 기반 강아지 모니터링 시스템

### 시스템 개요
MyDogCare는 실시간 AI 기반 강아지 모니터링 및 케어 시스템입니다. 온디바이스 AI 추론과 클라우드 데이터 분석을 결합하여 강아지의 행동, 건강 상태, 상호작용을 실시간으로 추적하고 분석합니다.

### 핵심 기능
1. **실시간 객체 탐지**: YOLO 기반 다중 강아지 탐지 및 추적
2. **개인 식별**: ReID(Re-Identification) 기술로 개별 강아지 식별
3. **행동 분석**: 놀이, 휴식, 추격 등 행동 패턴 분석
4. **스트레스 모니터링**: 강아지 스트레스 레벨 실시간 추정
5. **관계 분석**: 강아지 간의 친밀도, 긴장도 관계 분석
6. **AI 채팅**: 자연어로 강아지 상태 질의 및 분석
7. **케어 캘린더**: 수동 케어 이벤트 관리

### 기술 아키텍처
```
┌─────────────────┐    ┌─────────────────┐    ┌─────────────────┐
│   iOS 앱       │    │   백엔드       │    │   AI 모델      │
│   (SwiftUI)    │◄──►│   (FastAPI)    │◄──►│   (PyTorch)    │
│                 │    │                 │    │                 │
│ • 실시간 추론  │    │ • 데이터 저장   │    │ • 모델 학습   │
│ • UI 표시      │    │ • AI 채팅     │    │ • CoreML 변환 │
│ • 데이터 전송  │    │ • API 서비스   │    │                 │
└─────────────────┘    └─────────────────┘    └─────────────────┘
```

### 프로젝트 구조
- **ai-models/**: AI 모델 학습 및 CoreML 변환
- **backend/**: FastAPI 기반 REST API 서비스
- **ios-app/**: SwiftUI 기반 iOS 모바일 앱
- **mvp/**: MVP 개발 계획 및 문서

### 기술 스택
- **프론트엔드**: Swift, SwiftUI, Core ML, Vision
- **백엔드**: Python, FastAPI, DuckDB, OpenAI, Google AI
- **AI/ML**: PyTorch, YOLO, ReID, LLM
- **데이터베이스**: DuckDB (시계열), Core Data (로컬)

### 주요 사용자 시나리오
1. **24/7 모니터링**: 집에 설치된 카메라로 강아지를 지속적으로 모니터링
2. **행동 분석**: "오늘 버디가 얼마나 놀았어?"와 같은 질문에 AI가 답변
3. **건강 체크**: 강아지의 비정상 행동이나 건강 이상 신호 조기 발견
4. **관계 이해**: 여러 마리 강아지 간의 관계 동향 파악
5. **케어 관리**: 수동으로 케어 이벤트 기록 및 관리

### 데이터 흐름
```
카메라 영상 → YOLO 탐지 → ReID 식별 → 행동 분석 → 상태 패킷
      ↓
iOS 앱 실시간 처리
      ↓
HTTP API → 백엔드 서버 → DuckDB 저장
      ↓
사용자 질의 → LLM 분석 → SQL 쿼리 → 결과 반환
```

### 현재 개발 상태
- **MVP 단계**: 핵심 기능 구현 완료
- **AI 모델**: YOLOv11, ReID 모델 개발 완료
- **백엔드 API**: 기본 API 구현 완료
- **iOS 앱**: 주요 뷰 및 서비스 구현 완료
- **통합**: 부분 간 기본 통합 완료

### 향후 개발 방향
1. **모델 최적화**: 더 정확한 행동 분석 모델 개발
2. **웹 인터페이스**: 웹 기반 대시보드 개발
3. **알림 시스템**: 비정상 행동 자동 알림
4. **데이터 시각화**: 더 풍부한 차트 및 그래프
5. **사용자 개인화**: 개별 강아지별 맞춤 설정
